Acessar o Repositório:
No outro dispositivo, abra o navegador e acesse a página do seu projeto no GitHub:[https://github.com/euquemsabe714-ctrl/preciosidade-3d](https://github.com/euquemsabe714-ctrl/preciosidade-3d)

Baixar o Código como ZIP:

Procure por um botão verde escrito <> Código (ou Code) no canto superior direito da lista de arquivos.

Clique nele e escolha a última opção: Download ZIP. O navegador vai baixar uma pasta compactada com todo o seu app.

Extrair a Pasta:

Vá até a pasta de Downloads do dispositivo, clique com o botão direito no arquivo .zip baixado e escolha Extrair (ou "Extrair tudo").

Rodar o Aplicativo Offline:

Abra a pasta extraída.

Dê um duplo clique no arquivo index.html.

O aplicativo vai abrir diretamente no navegador e funcionará perfeitamente offline!
